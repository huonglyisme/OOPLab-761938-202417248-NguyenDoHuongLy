Lab 05 Answers

1. JavaFX application structure:
A JavaFX application contains Stage, Scene, and Nodes. FXML defines the UI layout, Controller handles user interactions, and Application class starts the program.

2. Scene Builder:
Scene Builder is used to design JavaFX UI visually and generate FXML files.

3. ObservableList:
ObservableList allows TableView to automatically update when the underlying list changes.

4. PlayerException:
PlayerException is thrown when a playable media has invalid length, such as length <= 0.

5. What happens if play() throws PlayerException but caller does not catch it?
The program will not compile because PlayerException is a checked exception.
